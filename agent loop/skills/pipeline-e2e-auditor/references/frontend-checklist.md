# 前端用户视角审计清单

## 页面级检查

逐页检查，每页记录以下维度：

### 数据展示
- [ ] 数字型数据是否出现 NaN、undefined、null、0（在不应为 0 的字段）
- [ ] 列表型数据是否为空（在不应为空的场景）
- [ ] 时间字段是否格式化正确（不显示时间戳原始值）
- [ ] 各卡片/表格的统计数字是否交叉一致（同一数据在不同位置是否相等）
- [ ] 题目总数、通过数、失败数是否满足算术关系（总数 = 通过 + 失败 + 未测）

### 交互行为
- [ ] 每个按钮点击后有响应（loading 态、结果更新、或错误提示）
- [ ] 下拉选择切换后页面数据是否联动刷新
- [ ] 表单提交后是否有成功/失败反馈
- [ ] 分页器：总数、每页条数、当前页是否匹配实际数据

### 状态同步
- [ ] 操作完成后，页面数据是否自动刷新（而非显示旧数据）
- [ ] 切换到不同 tab 后，数据是否对应变化
- [ ] 页面初始加载时的 loading 态是否正确过渡到数据态

### 错误处理
- [ ] 后端返回错误时，前端是否有用户可读的错误提示（不显示原始 stack trace）
- [ ] 网络断开时页面是否给出明确提示（而非白屏或无限 loading）

## 常见前端 bug 信号

以下现象出现任意一个，标记为疑似 bug：

- 页面闪了一下数据又变成空
- 数字显示为 0 但肉眼观察应该有数据
- 同样的数据在两个地方显示不一致
- 点击按钮后在 Network 面板看到 4xx/5xx 但页面无错误提示
- Network 面板中某个请求的 payload 里出现 undefined 或 [object Object]

## 不做什么

- 不评价 UI 美观度——只关注功能正确性
- 不根据前端源码推断行为——以浏览器实际渲染和 Network 面板为准
- 不因为"看起来正常"就跳过检查——每项必须实际点一遍
