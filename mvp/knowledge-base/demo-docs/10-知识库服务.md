# 知识库服务 API

## 服务地址
- 知识库服务运行在端口 8001
- 基础 URL: http://localhost:8001

## 端点列表

### 健康检查
- `GET /health` → {"status": "ok", "service": "knowledge-base"}

### 统计
- `GET /api/knowledge/stats` → {"collection": "documents", "total_chunks": N}

### 文档上传
- `POST /api/knowledge/upload` (multipart file) → 索引文件
- `POST /api/knowledge/upload-text?text=xxx&source=xxx` → 索引纯文本

### 语义搜索
- `GET /api/knowledge/search?q=xxx&top_k=5` → JSON 结果
- `GET /api/knowledge/context?q=xxx` → Markdown 格式上下文

### RAG 问答（核心）
- `POST /api/knowledge/ask`
  - 请求体: `{"question": "xxx", "top_k": 5}`
  - 返回: `{"answer": "...", "sources": [...], "model": "..."}`

### Logos 总结
- `POST /api/knowledge/logos`
  - 请求体: `{"conversation": "对话内容", "start_time": "10:30"}`
  - 返回: `{"file": "your-memory/2026-07-26.md"}`

### 策略管理
- `GET /api/knowledge/strategy` → 查看当前 RAG 策略
- `PATCH /api/knowledge/strategy` → 更新策略参数

### 索引管理
- `DELETE /api/knowledge/source?source=xxx` → 删除指定来源
