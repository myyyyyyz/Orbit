# 测试用例

## 后端 API 测试

### T001: 健康检查
- 请求：GET /health
- 预期：200, {"status": "ok"}

### T002: 用户注册
- 请求：POST /api/auth/register, {"username":"test_user","password":"123456"}
- 预期：200, 返回 access_token

### T003: 重复注册
- 请求：POST /api/auth/register, {"username":"test_user","password":"123456"}
- 预期：400, "用户名已存在"

### T004: 用户登录
- 请求：POST /api/auth/login, {"username":"test_user","password":"123456"}
- 预期：200, 返回 access_token

### T005: 错误密码登录
- 请求：POST /api/auth/login, {"username":"test_user","password":"wrong"}
- 预期：401, "用户名或密码错误"

### T006: 无 Token 访问
- 请求：GET /api/moments (无 Authorization 头)
- 预期：401

### T007: 创建瞬间
- 请求：POST /api/moments, {"title":"测试","content":"内容","date":"2025-06-15","tags":["测试"]}
- 预期：201, 返回创建的 moment

### T008: 获取时间线
- 请求：GET /api/moments
- 预期：200, 返回 moments 数组

### T009: 跨用户隔离
- 用户 A 创建瞬间 → 用户 B 获取时间线 → 预期空数组

### T010: 创建纪念日
- 请求：POST /api/anniversaries, {"name":"恋爱纪念日","date":"2025-06-15","type":"love_start"}
- 预期：201, 返回 days_until 和 days_since

### T011: 图片上传
- 请求：POST /api/upload, file=test.jpg
- 预期：200, 返回 image_url

### T012: 删除瞬间
- 请求：DELETE /api/moments/{id}
- 预期：200, {"message":"删除成功"}

### T013: 删除他人瞬间
- 用户 A 删除用户 B 的瞬间 → 预期 403
