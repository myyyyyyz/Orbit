# 恋心记录 LoveDiary — 产品概述

## 产品定位
恋心记录（LoveDiary）是一款专为情侣设计的甜蜜记录 Web 应用。用户可以记录恋爱点滴、设置纪念日倒计时、上传合照、记录约会位置。

## 核心功能
1. **时间线**：按日期倒序展示所有甜蜜瞬间，支持文字、图片、标签
2. **发布瞬间**：创建一条新记录，包含标题、内容、日期、标签、图片、位置
3. **纪念日倒计时**：设置重要日期，自动计算距今天数
4. **实时定位**：发布瞬间时可获取 GPS 位置，关联到记录
5. **图片上传**：支持上传图片到瞬间，预览和存储

## 用户角色
- 个人用户：情侣中的一方，注册后获得独立空间
- 情侣码：两人设置相同的 couple_code 可关联账号

## 技术栈
- 后端：FastAPI (Python)
- 前端：原生 HTML/CSS/JS
- 数据库：SQLite
- 认证：JWT Token
