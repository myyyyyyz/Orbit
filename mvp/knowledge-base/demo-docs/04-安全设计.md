# 安全设计规范

## 认证机制
- 所有 API 端点（除 /health、/api/auth/register、/api/auth/login）都需要 JWT Token
- Token 通过 `Authorization: Bearer {token}` 头传递
- 无 Token 或无效 Token → HTTP 401
- Token 有效期：7 天

## 密码安全
- 存储方式：SHA256 + 随机盐（16 字节 hex）
- 格式：`{salt}:{hash}`
- 验证：拆分 salt，重新计算 hash 对比
- 不存储明文密码

## 数据隔离
- 每个用户只能看到自己的 moments 和 anniversaries
- 通过 `user_id` 外键过滤实现
- CRUD 层的 `get_multi_by_user(user_id)` 方法确保隔离
- 跨用户访问他人数据 → HTTP 403

## CORS 配置
- 允许来源：`http://localhost:3000`, `http://127.0.0.1:3000`
- 允许方法：全部
- 允许头：全部
- 允许凭证：是

## 文件上传安全
- 最大文件大小：10 MB
- 允许格式：.jpg, .jpeg, .png, .gif, .webp, .bmp
- 文件名：UUID 生成，防止路径遍历攻击
- 存储路径：`uploads/` 目录，通过 StaticFiles 服务

## JWT 实现
- 算法：HS256
- Payload：`{"sub": username, "user_id": id, "exp": expiry}`
- 密钥：config.SECRET_KEY（生产环境必须更换）
