# 后端架构设计

## 分层架构
恋心记录后端采用经典的四层分离架构：

### 1. Models 层（数据模型）
- 文件：`app/models/{user,moment,anniversary}.py`
- 职责：定义 SQLAlchemy ORM 模型，映射数据库表
- 不含业务逻辑

### 2. Schemas 层（数据校验）
- 文件：`app/schemas/{user,moment,anniversary,common}.py`
- 职责：Pydantic 模型，请求/响应数据校验和序列化
- 例如：MomentCreate（创建请求）、MomentResponse（响应）

### 3. CRUD 层（数据操作）
- 文件：`app/crud/{base,user,moment,anniversary}.py`
- 职责：数据库操作封装
- CRUDBase 泛型基类提供 get/get_multi/create/update/remove
- 各模块特化方法如 get_by_username、get_multi_by_user

### 4. API 层（路由）
- 文件：`app/api/{auth,moments,anniversaries,upload}.py`
- 职责：HTTP 路由，调用 CRUD，返回响应
- 依赖注入：get_db（数据库会话）、get_current_user（认证）

## 认证模块
- 文件：`app/auth.py`
- JWT Token 签发与校验
- OAuth2PasswordBearer
- get_current_user 依赖注入

## 配置模块
- 文件：`app/config.py`
- Settings 类：DATABASE_URL、SECRET_KEY、UPLOAD_DIR 等
- 支持环境变量覆盖

## 入口
- 文件：`app/main.py`
- FastAPI 实例化
- CORS 中间件
- 静态文件服务（uploads）
- 路由注册
- 启动时创建数据库表
