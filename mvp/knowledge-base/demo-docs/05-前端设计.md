# 前端设计规范

## 设计风格
- 主题：温暖浪漫，专为情侣设计
- 主色调：粉色系暖渐变
  - --pink-100: #fff0f3
  - --pink-200: #ffccd5
  - --pink-300: #ff8fab
  - --pink-400: #ff6b9d
  - --pink-500: #e8507c
- 背景渐变：`linear-gradient(135deg, #fce4ec, #f8bbd0, #fce4ec, #fff0f3)`

## 卡片设计
- 背景：半透明毛玻璃效果 `rgba(255,255,255,0.75) + backdrop-filter: blur(16px)`
- 圆角：16px（大卡片 24px）
- 阴影：`0 2px 8px rgba(200,50,100,0.08)` ~ `0 8px 40px rgba(200,50,100,0.15)`
- 边框：`1px solid rgba(255,107,157,0.1)`

## 字体
- 系统默认 sans-serif
- 标题可用 serif

## 动画
- 心跳动画：logo 图标，`heartbeat 1.5s ease-in-out infinite`
- 淡入上移：时间线卡片，`fadeInUp 0.5s ease-out both`，每张延迟 0.08s
- 滑出展开：发布表单，`slideDown 0.3s ease-out`

## 响应式断点
| 断点 | 宽度 | 适配设备 |
|------|------|---------|
| 手机 | ≤ 375px | iPhone SE |
| 平板 | ≤ 768px | iPad |
| 桌面 | > 768px | 桌面浏览器 |

## 页面结构
1. 顶部导航栏（sticky + 毛玻璃背景）
2. 认证区域（未登录时显示登录/注册卡片）
3. 主内容区（已登录后）
   - 发布瞬间卡片
   - 纪念日卡片网格
   - 时间线列表
