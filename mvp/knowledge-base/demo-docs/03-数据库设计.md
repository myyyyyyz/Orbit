# 数据库 Schema 设计

## users 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer, PK | 自增主键 |
| username | String(50), unique | 用户名 |
| password_hash | String(128) | 密码哈希（SHA256 + 随机盐） |
| couple_code | String(20), index | 情侣码，用于关联两个用户 |
| created_at | DateTime | 创建时间 |

## moments 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer, PK | 自增主键 |
| user_id | Integer, FK→users.id | 所属用户 |
| title | String(100) | 瞬间标题 |
| content | Text | 瞬间内容 |
| date | String(10) | 日期 YYYY-MM-DD |
| tags | JSON | 标签数组 |
| image_url | String(500) | 图片 URL |
| latitude | Float | 纬度 |
| longitude | Float | 经度 |
| location_name | String(200) | 位置名称 |
| created_at | DateTime | 创建时间 |

## anniversaries 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer, PK | 自增主键 |
| user_id | Integer, FK→users.id | 所属用户 |
| name | String(100) | 纪念日名称 |
| date | String(10) | 日期 YYYY-MM-DD |
| type | String(20) | 类型：love_start/first_date/proposal/wedding/custom |
| created_at | DateTime | 创建时间 |

## 索引设计
- users.username: unique index
- users.couple_code: index
- moments.user_id: index
- moments.date: 用于排序
- anniversaries.user_id: index
