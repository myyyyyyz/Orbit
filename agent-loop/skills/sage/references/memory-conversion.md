# 记忆转化指南

## 什么值得记

非技术领域的"精华"不同于技术领域。技术解决方案可以直接复用，方法论需要场景判断。

| 记忆价值 | 类型 | 示例 |
|---------|------|------|
| ⭐⭐⭐⭐⭐ | 方法论 + 场景匹配 | "当你需要 [X] 时用 [方法 A]，需要 [Y] 时用 [方法 B]" |
| ⭐⭐⭐⭐ | 方法论的核心步骤 | "BATNA 谈判法的四步流程" |
| ⭐⭐⭐⭐ | 证伪/警告信息 | "学习风格 VARK 理论已被证伪，替代方案是..." |
| ⭐⭐⭐ | 方法论对比结论 | "金字塔原理 vs SCQA：各自适用场景" |
| ⭐⭐ | 单一方法论的详细解释 | 除非是高频复用场景，否则不记 |

## 什么不值得记

- 仅适用于一次性场景的建议
- 过于依赖文化背景的方法论（除非用户经常在该文化背景工作）
- 已经被证明低效的方法论（除非作为"反面教材"）
- 社交媒体上的流行但缺乏实证的技巧
- 纯个人偏好（"我习惯这样做"）

## 实例

```markdown
---
name: 谈判-BATNA
description: 谈判前确定最佳替代方案，防止接受过差条件
type: reference
credibility: A
validity: 5y
last-verified: 2026-07-13
---

## 来源
- [Harvard PON] [Getting to Yes](https://pon.harvard.edu) — 等级: A
- [HBR] [Negotiation Strategies](https://hbr.org) — 等级: A
- 搜索时间: 2026-07-13

## 方法论
**名称**：BATNA（Best Alternative to a Negotiated Agreement）
**核心**：谈判前先想清楚"如果谈不成，你的最优替代方案是什么"

## 使用指南
**适用场景**：
- 任何有退路的谈判（薪资、合作、采购、合同）
- 当你容易被对方气势压倒时

**不适用场景**：
- 没有替代方案（唯一供应商、只有一家公司给 offer）— 此时 BATNA 很弱，需用其他策略
- 长期关系维护 > 单次利益（家庭、挚友）

## 落地步骤
1. 列出如果谈不成的所有替代选项
2. 选出最优的那个（可量化最好：多少钱、什么条件）
3. 谈判中不断对比对方报价和你的 BATNA
4. 如果你的 BATNA 太弱，想办法先增强它

## 关联/对比方法论
- ZOPA：BATNA 决定你的底线，ZOPA 决定谈判区间
- 锚定效应：BATNA 帮助你抵抗对方锚定

## 争议/局限性
- 过度分析 BATNA 可能导致"分析瘫痪"，常见于完美主义者
- BATNA 必须在谈判前确定，谈判中动态调整要谨慎

## 更新记录
- 2026-07-13: 初次记录
```
