# 信源目录 / Source Catalog

## A 级信源（权威）

### 经典著作与学术

| 平台 | 覆盖领域 | 搜索方式 | 特点 |
|------|---------|---------|------|
| **Google Scholar** | 全领域 | `scholar.google.com` 按引用量排序 | 找高引论文作为方法论的科学证据 |
| **HBR (Harvard Business Review)** | 管理、领导、战略、决策 | `site:hbr.org {keyword}` | 管理学黄金标准，每篇文章经过严格编辑 |
| **McKinsey Quarterly** | 战略、组织、运营 | `site:mckinsey.com {keyword}` | 方法论发源地，MECE、7S 等经典模型出处 |
| **MIT Sloan Management Review** | 管理、创新、数字化转型 | `site:sloanreview.mit.edu {keyword}` | 学术与实践的桥梁 |
| **Stanford GSB** | 创业、领导、谈判 | `site:gsb.stanford.edu {keyword}` | 硅谷思想源头 |
| **Harvard Negotiation Project (PON)** | 谈判、冲突解决 | `site:pon.harvard.edu {keyword}` | 《Getting to Yes》来源，谈判学权威 |
| **Nielsen Norman Group** | UX、设计、可用性 | `site:nngroup.com {keyword}` | UX 研究领域最权威机构 |
| **PNAS / Nature / Science** | 心理学、认知科学、行为经济学 | `site:pnas.org {keyword}` | 顶级学术期刊 |

### 经典方法论著作（直接搜索）

这些著作本身是 A 级信源，搜索书名 + "summary" 或 "key points" 获取核心思想：

| 著作 | 相关方法论 | 领域 |
|------|----------|------|
| 《思考，快与慢》(Kahneman) | 系统1/系统2、前景理论、锚定效应 | 决策、判断 |
| 《金字塔原理》(Minto) | 金字塔原理、MECE | 沟通、写作 |
| 《Getting to Yes》(Fisher & Ury) | BATNA、原则谈判法 | 谈判 |
| 《影响力》(Cialdini) | 六大影响力原则 | 说服 |
| 《原子习惯》(Clear) | 习惯四步模型 | 效率、习惯 |
| 《刻意练习》(Ericsson) | 刻意练习原则 | 学习 |
| 《非暴力沟通》(Rosenberg) | NVC 四步法 | 沟通 |
| 《高效能人士的七个习惯》(Covey) | 七个习惯框架 | 效率、个人管理 |
| 《第五项修炼》(Senge) | 系统思考、学习型组织 | 问题解决、管理 |
| 《创新者的窘境》(Christensen) | 颠覆式创新理论 | 决策、战略 |
| 《设计思维》(Brown) | 设计思维五步法 | 创意、设计 |

## C 级信源（参考）

| 平台 | 特点 | 注意 |
|------|------|------|
| **Reddit** r/productivity, r/GetMotivated, r/DecidingToBeBetter | 真实用户经验和讨论 | 单个用户经验不代表普遍规律 |
| **Medium** | 个人博客和深度分析 | 质量参差不齐 |
| **知乎** | 中文讨论 + 实践案例 | 关注高赞和作者背景 |
| **播客** Tim Ferriss Show, Huberman Lab | 专家访谈 | 访谈不等于学术验证 |
| **YouTube** 教育频道 | 方法论可视化 | 娱乐性可能大于学术性 |

