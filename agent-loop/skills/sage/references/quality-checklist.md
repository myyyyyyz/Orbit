# 搜索质量自检清单

## 每次回答前必须检查

### 信源检查

- [ ] 是否搜索了至少 1 个 A 级信源（经典著作/HBR/McKinsey/高引论文）
- [ ] 是否搜索了至少 1 个 B 级信源（Farnam Street/LessWrong/TED/大学课程）
- [ ] 信源是否为近 5 年内（新兴领域）或仍有影响力（经典领域）
- [ ] 所有引用是否标注了信源等级（A/B/C）
- [ ] 是否标注了来源链接（非仅平台名）

### 方法论检查

- [ ] 推荐的方法论是否与用户场景匹配
- [ ] 是否包含了"适合场景"和"不适合场景"
- [ ] 是否给出了可执行的落地步骤（3-5 步）
- [ ] 是否执行了证伪检查（搜索过 criticism/limitations）
- [ ] 如果有争议，是否已标注

### 可操作性检查

- [ ] 用户看完能否立刻开始做第一步
- [ ] 推荐是否具体到了"怎么做"，而不是"要重视 XX"
- [ ] 是否有过度抽象的概念需要拆解

### 边界检查

- [ ] 是否区分了方法论和个人经验
- [ ] 是否标注了不确定性
- [ ] 是否避免了绝对化表述（"永远""一定""所有"）
- [ ] 是否适合用户的文化/语言环境

## 常见搜索失误

| 失误 | 后果 | 预防 |
|------|------|------|
| 凭记忆推荐方法论 | 遗漏最新研究或争议 | 必须搜索后再推荐 |
| 不执行证伪检查 | 推荐已被推翻的理论 | 强制搜索 criticism |
| 忽略"不适合场景" | 用户在不合适的场景中套用 | 每个推荐必须有"不适合场景" |
| 推荐太抽象 | 用户用不起来 | 必须有具体落地步骤 |
| 忽视文化差异 | 西方管理方法在东方失效 | 搜索中文环境下的应用案例 |
| 单一信源 | 被某一学派观点带偏 | 至少跨 2 类信源交叉验证 |

## 领域特殊检查

### 心理学/认知科学

- [ ] 是否考虑了"复制危机"影响（很多经典心理学实验未能成功复制）
- [ ] 引用的研究是否有独立重复验证
- [ ] 效应量是否实际显著（不仅仅是统计显著）

### 管理学

- [ ] 是否考虑了公司规模和行业差异（大厂实践不一定适合小团队）
- [ ] 是否区分了"描述性"和"规范性"（这个方法论在说"是什么"还是"应该怎么做"）

### 学习方法

- [ ] 是否区分了"证据强"和"流传广"（学习风格理论流传广但被证伪）
- [ ] 是否考虑了学习者的先验知识水平
