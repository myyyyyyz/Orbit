## 证伪搜索（所有策略通用）

推荐任何方法论前，必须执行：

```
搜索: "{方法论名} criticism" OR "debunked" OR "limitations"
搜索: "{方法论名} doesn't work" OR "ineffective"
搜索: "{方法论名} controversy" OR "debate"
```

### 处理原则

| 证伪结果 | 处理方式 |
|---------|---------|
| 有 A/B 级信源质疑但未被完全推翻 | 在推荐中标注"⚠️ 存在争议"，列出具体质疑点 |
| 已被学术界明确证伪 | 标注"🚫 已被证伪"，给出替代方案 |
| 有理论局限性（非证伪） | 在"不适合场景"中标注 |
| 无任何负面评价 | 注意：可能意味着该方法论使用不广泛，而非完美 |
