# Sage — 非技术领域方法论与思维模型

遇到非技术决策、沟通、管理、谈判、学习等问题时，自动搜索并推荐最匹配的方法论和思维模型。

## 可以问什么

### 决策与判断
- "两个候选人选哪个？决策完又在纠结怎么办？"
- "要不要离职去创业？怎么评估风险？"
- "产品方向 A 和方向 B，团队意见分歧，怎么选？"

### 沟通与说服
- "怎么写一封让老板批准的预算申请邮件？"
- "给 CEO 做汇报，5 分钟怎么把事说清楚？"
- "要否决一个合作方的方案，怎么说才能不伤关系？"

### 管理与领导
- "新带的团队效率持续下降，可能是什么原因？"
- "下属总是做完了不说，我最后一天才知道出问题，怎么改？"
- "怎么给一个表现不错但态度有问题的同事做绩效反馈？"

### 谈判与冲突
- "谈薪资的时候怎么报价不亏？"
- "两个部门抢资源，我是中间协调人，怎么办？"
- "甲方一直压价，合同还有一周到期，有什么谈判方法？"

### 学习与认知
- "下周要面试，一个月没看的东西怎么最快捡起来？"
- "看书总感觉看了就忘，有没有被验证有效的学习方法？"
- "每天只有 1 小时学习时间，怎么安排效率最高？"

### 问题解决
- "用户流失了 30% 但找不到原因，怎么排查？"
- "一个持续了半年的老问题，团队已经试过所有能想到的办法，还能怎么办？"
- "问题太复杂不知道怎么下手，有没有分解框架？"

### 创意与设计
- "团队开会想不出新点子，每次都那几句，有什么能激发创意的流程？"
- "产品改版，怎么验证新设计真的比旧的好？"
- "怎么写销售文案能让用户有冲动下单？"

### 效率与习惯
- "每天被消息打断十几次，有什么方法能保持深度工作？"
- "设的目标每年都完不成，是不是目标设定方式有问题？"
- "总在截止日前赶工，怎么打破这个循环？"

## 结构

```
sage/
├── SKILL.md                           # 主 Skill 文件
├── README.md                          # 本文件
├── references/
│   ├── source-catalog.md              # 信源目录（A/B/C 级信源清单）
│   ├── search-strategies.md           # 各领域搜索策略
│   ├── quality-checklist.md           # 搜索质量自检
│   ├── memory-conversion.md           # 记忆转化指南
│   └── known-debunked-models.md       # 已知需警告/证伪的方法论
├── examples/                          # 使用示例
├── memory/                            # 转化后的记忆
└── scripts/                           # 辅助脚本
```

## 核心原则

1. **先搜索再回答** — 不凭记忆推荐方法论
2. **必须有信源** — 每个推荐标注来源和等级
3. **区分适合/不适合** — "不适合场景"比"适合场景"更重要
4. **证伪检查** — 推荐前搜索 criticism/limitations
5. **可执行** — 每一步用户都能立刻做
